# Classes and Objects – C++

This section contains practical examples of Object-Oriented Programming (OOP) in C++.

## Copy Constructor

The  Copy Constructor (&) .cpp  example demonstrates:

- Creating objects using constructors.
- Copying an existing object using a copy constructor.
- Understanding how objects maintain independent values.
- Using member functions to display object data.

## Learning Objective

Understand how copy constructors work in C++ and how modifying a copied object's value does not affect the original object in this example.
