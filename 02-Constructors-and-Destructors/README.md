# Constructors and Destructors – C++

## Constructors, Copy Constructors, and Destructors

This section demonstrates how object creation, copying, and destruction work in C++.

### Concepts Covered

- **Constructor:** Initializes a new object and increases the shared object counter.
- **Copy Constructor:** Creates a new object by copying an existing object.
- **Destructor:** Executes when an object is destroyed and decreases the object counter.
- **Static Members:** Uses a shared variable to track the number of active objects.
- **Pass by Value:** Demonstrates how passing an object to a function creates a copy.
- **Object Lifetime:** Explores the order in which constructors and destructors are executed.

### Learning Objective

Understand how C++ manages object creation, copying, and destruction, and how these operations affect the lifetime and state of objects.
